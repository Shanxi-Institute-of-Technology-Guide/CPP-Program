# C++ Programming Exercises

This directory contains small C++ programs for learning functions, classes, inheritance, polymorphism, and simple calculations.

> Academic context: this directory contains course lab or coursework solutions.

## Files

- `Hello.cpp`: basic output
- `function.cpp`: functions
- `clazz.cpp`: classes and objects
- `inherit.cpp` and `Polymorphism.cpp`: object-oriented programming
- `profit.cpp`: calculation exercise

## Compile and Run

```powershell
g++ -std=c++20 -Wall -Wextra -o hello Hello.cpp
.\hello.exe
```

Compile each exercise separately because the files are standalone programs.
