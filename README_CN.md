# C++ 语言练习

本目录包含用于学习函数、类、继承、多态和简单计算的 C++ 小程序。

> 课程说明：本目录收录课程实验或课程作业的解决方案。

## 文件说明

- `Hello.cpp`：基础输出
- `function.cpp`：函数
- `clazz.cpp`：类和对象
- `inherit.cpp` 与 `Polymorphism.cpp`：面向对象编程
- `profit.cpp`：计算练习

## 编译运行

```powershell
g++ -std=c++20 -Wall -Wextra -o hello Hello.cpp
.\hello.exe
```

每个练习都是独立程序，应分别编译。
